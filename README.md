הפרויקט הזה הוא מחשבון מורכב שמשתמש בשתי מחסניות וארבעה מילונים כדי לפתור ביטויים מתמטיים בצורה חכמה. המילונים מחלקים את העבודה כך שיש הגדרה ברורה לסדר העדיפויות, לפעולות בין שני מספרים (כמו ממוצע @), ולפעולות על מספר בודד שבאות לפני או אחרי המספר (כמו עצרת !). השתמשתי במחסנית אחת למספרים ובשנייה לאופרטורים כדי לנהל נכון את סדר הפעולות, כולל מקרים מסובכים של מינוס לפני מספר או חזקות. המבנה הזה מאפשר למחשבון לתמוך בהרבה פעולות מיוחדות כמו סכום ספרות (#) או מציאת מקסימום ($) בקלות וביעילות.
